# Mute Inactive Tabs & YouTube Shorts Auto-Pause

A lightweight Chrome Extension (Manifest V3) that automatically mutes inactive tabs and intelligently pauses/resumes YouTube Shorts when switching tabs.

## 🚀 How to Install (60 seconds)

1. Click **Code** > **Download ZIP** at the top right of this page and extract it.
2. Open Chrome and go to `chrome://extensions/`.
3. Toggle on **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the extracted folder.

## ⌨️ Shortcuts
* Press `Alt + Shift + M` to toggle the extension ON/OFF anytime.
